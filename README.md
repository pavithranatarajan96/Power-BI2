Power BI Dashboard Assignment

📌 Project Overview

This repository contains the submission for the Power BI Assignment. The project involves analyzing structured datasets, building an interactive data model, and designing an intuitive multi-visual report using modern themes and customized visuals.

The project file (.pbix) has been structured and validated using custom Power BI report definitions, including custom theme integration (Fluent2 and Frontier base themes) and dynamic visual layouts.

📂 Repository Structure

├── Report/
│   ├── definition/
│   │   ├── pages/            # Page layouts and dynamic visual definitions
│   │   ├── report.json       # Core report metadata and configuration
│   │   └── version.json      # Report schema versioning
│   └── StaticResources/
│       └── SharedResources/  # Base themes (Fluent2, Frontier)
├── DataModel                 # Data schema, tables, and relationship definitions
├── [Content_Types].xml       # Package content specification
└── README.md                 # Project documentation


📊 Key Features & Analysis

Interactive Visualizations:

Custom-designed layout pages featuring tailored visuals (KPI cards, bar/line charts, tables/matrix views).

Configured with visual-level interactivity, drill-throughs, and dynamic filters.

Data Modeling & DAX:

Formatted and structured data model linking multiple data tables.

Calculated columns and DAX measures built to support KPI tracking and key business metrics
Integrated modern UI/UX principles utilizing the Fluent2 design system and Frontier theme assets for consistency, readability, and accessibility.
